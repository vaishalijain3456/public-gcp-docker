Demo Links -- Day 1 to Day 13

=== Local (run these yourself for the full working demo) ===
React app:
  cd mini-project-react && npm run dev
  Then open: http://localhost:5173  (Vite may use 5174 etc. if 5173 is busy)
  Shows: Home, CRUD, and External API pages -- routing, full CRUD,
  real-time feed, pagination, directives, error boundary, code-split pages.

GraphQL server (backend) / GraphiQL explorer:
  cd graphql-server && npm run dev
  Then open: http://localhost:4000/graphql
  Run queries, mutations, and subscriptions directly here.

Note: the local React app and local GraphQL server must both be running
at the same time for CRUD/Home to work. The External API page does not
need the local GraphQL server (it talks to a real public API instead).
